# Airspace

Airspace is divided into different classes based on the level of ATC services provided, operating requirements, and equipment requirements.

For controllers, knowing the boundaries and requirements of each class is essential when determining what services and clearances are required.

## Airspace Classes

The primary controlled airspace classes are:

| Class | General Description                                                    |
| ----- | ---------------------------------------------------------------------- |
| A     | High-altitude controlled airspace                                      |
| B     | Airspace surrounding the busiest airports                              |
| C     | Airspace surrounding airports with significant IFR operations          |
| D     | Airspace surrounding airports with an operating control tower          |
| E     | Controlled airspace that does not meet the requirements of Classes A–D |
| G     | Uncontrolled airspace                                                  |

---

# Class A

Class A airspace generally extends from:

**18,000 feet MSL to and including FL600.**

Class A is:

- IFR only
- Controlled airspace
- Subject to ATC clearance
- Separated using IFR procedures

Aircraft operating in Class A must operate under IFR.

### Controller Considerations

When an aircraft climbs into Class A airspace:

- An IFR clearance is required.
- ATC separation standards apply.
- Flight levels are used.
- Direction of flight determines the applicable cruising altitude.

---

# Class B

Class B airspace surrounds the busiest airports and is designed to protect high volumes of IFR and VFR traffic.

Class B airspace is commonly depicted as a series of layered shelves surrounding the primary airport.

### Entry

VFR aircraft must receive an explicit ATC clearance to enter Class B.

A pilot's request or controller instruction to "proceed through" the airspace does not by itself constitute a Class B clearance unless the appropriate clearance is issued.
