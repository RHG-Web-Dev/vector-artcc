# KMEM Clearance Delivery

A practical KMEM clearance delivery reference for VATSIM controller training. Facility-specific procedures and current ZME documentation take precedence over this page.

## Local Quick Notes

- Review the current Memphis/ZME departure and reference materials before a session.
- Training notes currently call out **ELVIS4** as the standard IFR-probable departure. Confirm the current procedure before using it operationally.
- Review equipment suffixes when evaluating whether an aircraft can accept a departure.
- For route planning, use current charts and filed-route information rather than relying on an old example.

## Clearance Workflow

### 1. Identify the Request

```text
[CALLSIGN] Looking for IFR Clearance to [Airport].
```

If the clearance is not immediately ready:

```text
[CALLSIGN] Memphis Ground, Clearance on Request Number [POSITION].
```

### 2. Prepare the Clearance

Use [CRAFT](/reference/craft/) to organize the clearance:

- Clearance limit
- Route
- Altitude
- Frequency
- Transponder

### 3. Amend When Necessary

If the filed departure is unavailable or incompatible, offer the appropriate alternative and then issue the amended clearance. See [Amendments](/reference/amendments/).

### 4. Verify the Readback

Confirm the route, altitude, frequency, squawk, and any amended item. See [Readbacks](/reference/readbacks/).

## Ground / Tower Coordination Notes

Training notes also call out **Sierra** as a location where Tower may withhold a crossing and recommend establishing blanket-crossing expectations at the start of a session when appropriate.

Because crossing practices are facility- and configuration-dependent, verify the current SOP before using blanket coordination.
