# Amendments

An amendment changes part of an aircraft's previously issued clearance.

Common amendments include:

- Route
- Altitude
- Departure procedure
- Arrival procedure
- Transition
- Clearance limit
- Other restrictions or instructions

## Basic Amendment Structure

When amending a clearance, clearly identify what is changing and provide the new information in standard phraseology.

For a route amendment:

```text
AMEND ROUTE TO READ...
```
